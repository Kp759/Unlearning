## Pipeline cost

Routing pass, ms per prompt: full forward 3.11; stop_after_L19 1.94; stop_after_L26 2.59 (28 blocks). Ours makes ONE pass: the router reads the L19 state at the prompt's last token and the row is added at L19 in the same pass. Reading a later layer L means either a second pass (route at L, write at L19: the early-write model, one extra prompt pass cut short at L) or moving the edit up to L as well, which changes the edit itself.
