## Pipeline cost

Routing pass, ms per prompt: full forward 1.81; stop_after_L19 1.32; stop_after_L26 1.76 (28 blocks). The deployed early-write model (scripts/early_write.py) already makes two passes: pass 1 routes on the prompt (cached per prompt, not per generated token), pass 2 writes at L16. Reading a later layer does not add a pass, because the L16 write is below the read layer whichever it is. It only changes how far pass 1 must run if it is stopped at the router layer (today it runs the full model).
